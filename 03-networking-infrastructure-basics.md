\# Networking Infrastructure Basics



\## Overview



This document summarizes basic networking infrastructure topics for beginners: PoE, fiber optic cables, switch port security, and Cisco Packet Tracer.



\---



\## Power over Ethernet (PoE)



PoE allows one Ethernet cable to carry both data and power.



Common devices:



\* IP Phone

\* CCTV Camera

\* Wireless Access Point



Key terms:



\* \*\*PSE\*\*: Device that provides power

\* \*\*PD\*\*: Device that receives power

\* \*\*PoE Budget\*\*: Total power available from a PoE switch



\---



\## Fiber Optic Cable



Fiber optic cable sends data using light.



Main types:



\* \*\*Multimode\*\*: Short distance

\* \*\*Single Mode\*\*: Long distance



Key advantages:



\* High speed

\* Long distance

\* High bandwidth

\* Resistant to electrical interference



\---



\## Switch Port Security



Switch port security helps prevent unauthorized devices from accessing the network.



Basic protection:



\* Disable unused ports

\* Use an isolated VLAN

\* Limit allowed MAC addresses

\* Use sticky MAC when needed



Violation modes:



\* Protect

\* Restrict

\* Shutdown



\---



\## Cisco Packet Tracer



Cisco Packet Tracer is a virtual lab tool for learning networking without physical hardware.



It can be used to practice:



\* IP addressing

\* Ping testing

\* Switch and router configuration

\* VLANs

\* DHCP

\* Routing
