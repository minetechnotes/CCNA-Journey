\# Packet Tracer \& Basic Networking



\## Overview



Packet Tracer is a Cisco tool used to practice networking virtually.



\---



\## Basic Network



```text

PC1 ── Switch ── PC2

```



Example:



```text

PC1: 192.168.1.10

PC2: 192.168.1.11

Mask: 255.255.255.0

```



Test connection:



```bash

ping 192.168.1.11

```



Reply means the network is working.



\---



\## Key Concepts



```text

Switch   = connects devices in LAN

IP       = device address

Ping     = connection test

Ethernet = wired network standard

UTP      = Ethernet cable type

```



\---



\## UTP Cable



UTP cable has:



```text

8 wires

4 twisted pairs

```



T568B order:



```text

White-Orange

Orange

White-Green

Blue

White-Blue

Green

White-Brown

Brown

```



\---



\## Packet Tracer Tools



```text

Realtime Mode   = normal testing

Simulation Mode = see packet movement

Notes           = add information

Save File       = save lab

```



\---



\## Summary



Packet Tracer helps beginners practice basic networking.

The main goal is to understand how devices connect and communicate.
