\# Ethernet Cable Basics



\*\*Overview\*\*



An Ethernet cable is a LAN cable used to connect devices in a local network.



```text

Laptop → Router

PC → Switch

Printer → Switch

Access Point → Switch

```



Ethernet uses a physical cable to send and receive data.



\---



\*\*Why It Matters\*\*



Ethernet cable knowledge is important for networking, CCNA, IT support, and cybersecurity.



It helps troubleshoot basic network issues such as:



\* Bad cable

\* Loose RJ45 connector

\* Wrong wire order

\* Weak crimping

\* Inactive switch port



\---



\*\*Tools Needed\*\*



\* Cat5e or Cat6 cable

\* RJ45 connector

\* Crimping tool

\* Cable tester



\---



\*\*T568B Color Order\*\*



T568B is one of the most common Ethernet wiring standards.



```text

1\. White Orange

2\. Orange

3\. White Green

4\. Blue

5\. White Blue

6\. Green

7\. White Brown

8\. Brown

```



The wire order must be correct for the cable to work properly.



\---



\*\*Cable Types\*\*



\*\*Straight-Through Cable\*\*



A straight-through cable uses the same wire order on both ends.



```text

T568B → T568B

```



Common use:



```text

PC → Switch

Laptop → Router

Printer → Switch

```



This is the most common Ethernet cable type.



\*\*Crossover Cable\*\*



A crossover cable uses different wire orders on each end.



Older use cases:



```text

PC → PC

Switch → Switch

```



Today, crossover cables are rarely needed because modern devices support Auto-MDIX.



\---



\*\*Basic Steps\*\*



```text

1\. Cut the cable

2\. Strip the outer jacket

3\. Arrange the wires using T568B

4\. Insert the wires into the RJ45 connector

5\. Crimp the connector

6\. Repeat on the other end

7\. Test the cable

```



If the cable tester shows `1 2 3 4 5 6 7 8` in order, the cable is working correctly.



\---



\*\*Cable Length Limit\*\*



```text

Maximum copper Ethernet length = 100 meters

```



For longer distances, fiber optic cable is usually a better option.



\---



\*\*Summary\*\*



```text

Ethernet cable = LAN cable

RJ45 = Ethernet connector

T568B = Common wire order

Straight-through = Most common Ethernet cable

Crossover = Older cable type for similar devices

Max length = 100 meters

```



\---



\*\*Conclusion\*\*



Ethernet cable is a basic but important networking skill.



Understanding it helps beginners troubleshoot real network problems from the physical layer.
