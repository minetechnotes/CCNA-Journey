Small Business Network Basics



\## Overview



This document summarizes the basic components of a small business network.



Example network:



```text

User Device → Access Point / Switch → Router → Internet

````



\---



\## LAN vs WAN



```text

LAN = internal network

WAN = external network / internet

```



Example:



```text

PC → Switch → Printer      = LAN

Router → ISP → Internet    = WAN

```



\---



\## Core Network Devices



```text

Switch       = connects local devices

Router       = connects LAN to internet

Access Point = provides Wi-Fi

Firewall     = protects the network

```



Example:



```text

Internet

&#x20;  ↓

Router / Firewall

&#x20;  ↓

Switch

&#x20;  ├── Server

&#x20;  ├── Printer

&#x20;  ├── Access Point

&#x20;  └── Cashier PC

```



\---



\## Client and Server



```text

Client = device that requests a service

Server = device that provides a service

```



Example:



```text

Laptop → requests file → File Server

Phone  → opens website → Web Server

```



\---



\## Ethernet Speed



Network speed uses bits.



File size uses Bytes.



```text

1 Byte = 8 bits

```



Example:



```text

1 Gbps = 1000 Mbps

1000 Mbps ÷ 8 = 125 MBps

```



\---



\## Copper vs Fiber



```text

Copper = short distance

Fiber  = long distance

```



Example:



```text

PC → Copper Cable → Switch

Building A → Fiber Cable → Building B

```
